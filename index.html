給帶領的老師

FOR TEACHERS

玩之前的三個約定

不貼標籤不拿遊戲裡的人比對班上同學，焦點放在感受和需要。
看見環境同一個人換了環境就做得到。可以調整的，是教室和我們的做法。
問本人每個人都不一樣。想了解一個人，用對方舒服的方式問本人。

建議的一節課流程・45 分鐘

  1. 5′開場暖身玩「暖身：同一句話」，問：你有沒有覺得某種聲音、光線特別受不了？
  2. 15′進入關卡每人選一關，或全班一起玩同一關。
  3. 15′小組分享最難受的時刻，和那時最希望別人怎麼做。
  4. 10′全班整理列出「我們班可以做的三件小事」。

討論可以問

  • 哪一個時刻讓你最不舒服？你那時在想什麼？
  • 有支持和沒有支持，差在哪裡？哪一項改變最有用？
  • 同學一句話、一個眼神，會讓那個時刻變好還是變糟？
  • 你自己有沒有需要別人多等你一下的時候？

聲光提醒：「世界太大聲的一天」有突然的大聲響與閃白畫面，對聲光敏感的學生可以先調小音量、勾選「減少閃爍」，或改看同學操作。
遊戲中的人物和情境都是虛構的，只模擬部分經驗，不能代表任何一個人，也不能用來判斷別人。電腦或平板用 Chrome、Edge 開啟效果最好。

小提示建議戴耳機，聲音也是體驗的一部分。 七年三班・早上 08:10 CLASS 7-3
